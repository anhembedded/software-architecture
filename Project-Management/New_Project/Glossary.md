# 📖 Glossary — Project Management English

> [!abstract] TL;DR
> Learn **verb + noun chunks**, not single words. Each term is tied to a step in this folder and to PMBOK wording.

Index: [[Thinking New project]] · Mapping: [[PMBOK Mapping]]

| --- | --- | --- |

| survey the architecture | study how the system is organized | [[02 Discover]] |

## 2. Core terms

| Term | Meaning |
| --- | --- |
| **stakeholder** | a person or group affected by, or affecting, the project |
| **requirement** | what the system must do or achieve |
| **constraint** | a limit (time, hardware, standards) |
| **assumption** | something taken as true without proof |
| **scope** | what is in and out of the project |
| **scope creep** | uncontrolled growth of scope |
| **deliverable** | a product or result handed over |
| **acceptance criteria** | conditions that must be met for sign-off |
| **milestone** | a significant checkpoint |
| **dependency** | a relationship where one task needs another |
| **blocker** | something that stops progress |
| **open question** | a question without an answer yet |
| **feasibility** | whether it can realistically be done |
| **vertical slice** | a thin end-to-end cut through all layers |
| **regression** | an old bug or failure that returns after a change |
| **hardening** | making a product robust before release |
| **handover** | passing the work to another owner |
| **impact analysis** | studying what a change will affect |
| **timebox** | a fixed time limit for an activity |

## 3. PMBOK terms

| Term | Meaning |
| --- | --- |
| **Process group** | Initiating, Planning, Executing, Monitoring & Controlling, Closing |
| **Knowledge area** | one of 10 management topics (Scope, Schedule, Risk, …) |
| **Project charter** | document that authorizes the project and states objectives |
| **WBS** | Work Breakdown Structure: scope split into work packages |
| **Progressive elaboration** | adding detail as more is learned |
| **Rolling wave planning** | detail the near term, keep the far term rough |
| **Risk register** | list of risks, rankings and responses |
| **Assumption log** | list of assumptions and constraints |
| **Issue log** | list of problems, owners and status |
| **Lessons learned register** | notes of what the project learned |
| **EEF** | Enterprise Environmental Factors (conditions outside your control) |
| **OPA** | Organizational Process Assets (company templates, history) |
| **Control Quality** | verify that deliverables are correct |
| **Validate Scope** | get formal customer acceptance |
| **Integrated Change Control** | review and approve changes in a controlled way |
| **Contingency reserve** | time or budget kept for known risks |
| **Tailoring** | adapting the approach to the project context |
| **Performance domain** | 7th ed.: a group of related activities (Planning, Delivery, Uncertainty, …) |
